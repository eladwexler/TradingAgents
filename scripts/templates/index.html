The call

BASE vs MACRO
BASE = the call from the company's own fundamentals (bottom-up). MACRO = the same call after adjusting for where we are in the AI-spending cycle (a top-down reality check). When MACRO is more cautious than BASE, the cycle is the reason.
Buy
"Own a lot of this." Strong conviction, full-size position.
Overweight
"Own more than average, but sized small for the risk." Positive with caveats.
Hold
"Neither add nor sell." Evidence is genuinely two-sided.
Underweight
"Own less than average." Leans negative, not a hard exit.
Sell
"Don't own it." Exit or avoid.
Colors
green = constructive · amber/grey = neutral/hold · red = cautious/negative.

Secular lenses (is it on the right side of the AI build-out?)

Jensen Brain
Would Jensen Huang / NVIDIA strategically back this company? Likely back = sits with NVIDIA's platform · Possible = benefits from the theme but not a clear bet · Unlikely back = builds a rival/substitute · Insufficient = too little said to judge.
Leopold Brain
Does it fit Leopold Aschenbrenner's AGI-build-out thesis (compute, power/grid, chips)? Thesis tailwind = a beneficiary/enabler · Possible = partial fit · Thesis headwind = the build-out commoditizes or AGI disrupts it · Insufficient = too thin.
Jordi Brain
Does it sit with Jordi Visser's macro / AI-capex thesis? Constructive = an AI-capex / compute-scarcity / power / bitcoin / physical-AI beneficiary (or a productivity winner like Palantir) · Possible = mixed · Cautious = on the wrong side of his creative destruction (legacy SaaS, ROIC-gap neoclouds, labor disruption) · Insufficient = outside his framework.
Gavin Brain
Would Gavin Baker (Atreides) back it as an AI winner — is AI sustaining (strengthens the moat: data, distribution, scale, compute) or disruptive (erodes it)? Conviction pick = strong, direct, repeated backing (STRICT bar) · Possible = framework fit, no direct call · Cautious = AI disrupts/commoditizes it · Insufficient = he doesn't cover it.
X Brain
What X (Twitter) FinTwit/AI is saying — crowd sentiment + trend buzz (keyless corpus). Bullish buzz / Mixed / Bearish / Insufficient chatter. A sentiment overlay, the latest & noisiest signal — separate from the four secular brains and NOT part of the Combined verdict. See the Research tab for aggregate trends + the most-bullish names.
Combined
The four lenses fused (sum −4..+4; any sign-split → CONTESTED): CONVICTION ALIGNED (all positive) → ALIGNED → NEUTRAL → CONTESTED (they disagree) → EXPOSED → OFFSIDE (all negative). It flags the secular tailwind; it does not change the Buy/Hold/Sell call.

Forecast numbers

P(beat benchmark)
The model's probability (0–1) the stock beats its benchmark (US stocks → the S&P 500) over the horizon. 0.50 = coin-flip; above ~0.60 is a real edge. This is the number later graded for accuracy (Brier score).
Expected return
The probability-weighted total return over the horizon (price move + dividends), blending the bear/base/bull cases.
CAGR
That same return expressed per year (compound annual growth rate).
Bear / Base / Bull
The pessimistic / most-likely / optimistic price scenarios behind the forecast.
Target
The single headline expected price at the horizon.
Horizon
The holding period the forecast covers — default 24 months.
Benchmark / alpha
Benchmark = what the stock is measured against. Alpha = return above the benchmark (out-performance). Shown only once a call has matured.

Status & this page

Pending vs Resolved
Pending = the horizon hasn't matured, so it's graded later. Resolved = the real outcome (raw return + alpha) has been recorded.
Analyses (N×)
How many times this stock has been run through the tool (see By stock below).
Track-record cards
Across all matured calls: how many beat their benchmark (hit-rate) and the average out-performance (mean alpha).
